# Cycloidal isochronous pendulum simulator


This repository contains C++ and Python code to simulate the motion of a cycloidal pendulum with the effects of aerodynamic drag and friction between the string and the wall.

## Requirements:
**C++ standard:** C++20 Standard
**Python libraries:** 'matplotlib', 'csv'


## Features:

**Numerical solution:** Integration of the ODE with Runge-Kutta-Fehlberg method (RK45).

**Theoretical basis:** Hysteresis is modeled with the $\mu_{eq}\cdot N$ equation and the $C_D$ approximated with best-fit curves with $Re$ as a parameter.

**Empirical validation:** $\mu_eq$ is calculated by confronting energy dissipation in the numerical simulation and in the data extracted from video tracking the physical pendulum.

**Implementations:** Linear algebra is handled with the Eigen library. Other declarations are in the "include" directory.

## Equation of motion

The isochronous pendulum follows this equation: $$m\ddot{s} + m\frac{g}{4R}s + \frac{1}{2}\rho C_D A \dot s^2 \text{sgn}(\dot s) + \mu_{eq} N \text{sgn}(\dot {s}) = 0$$



## Using the code

```bash

git clone https://github.com/catellanidiego/bachelor_thesis

cd bachelor_thesis

mkdir build

cd build

cmake ..

make

./main

```



## Results and Visualization

**Output Data:** The simulation results are exported in '.csv' format.

**Graphs:** Kinematics plots can be generated by running the Python scripts located in the 'src' directory.

```bash
./data_for_mu_eq

./mu_eq

```
