\# Cycloidal isochronous pendulum simulator



This repository contains C++ and Python code to simulate the motion of a cycloidal pendulum with the effects of aerodynamic drag and friction between the string and the wall.



\## Features:

\-\*\*Numerical solution:\*\* Integration of the ODE with Runge-Kutta-Fehlberg method (RK45).

\-\*\*Theoretical basis:\*\* Friction is modeled with the Coulomb dry friction equation and C\_D is approximated with the Stokes' and White's regimes.



\## Equation of motion

The isochronous pendulum follows this equation: $$\\ddot{s} + \\frac{g}{4R}s + \\frac{1}{2}\\rho C\_D A \\dot s^2 \\text{sgn}(\\dot s) + \\mu\_d N \\text{sgn}(\\dot {s}) = 0$$



\## Using the code

```bash

git clone https://github.com/catellanidiego/bachelor\_thesis

cd bachelor\_thesis

mkdir build

cd build

cmake ..

make

./main

```



\## Results and Visualization

\-\*\*Output Data:\*\* The simulation results are exported in '.csv' format.

\-\*\*Graphs:\*\* Kinematics plots can be generated by running the Python scripts located in the 'src' directory.



\## Testing

Tests can be launched directly from the terminal.

```bash

cd build

ctest

```
